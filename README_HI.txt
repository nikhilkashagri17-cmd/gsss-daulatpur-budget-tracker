GSSS DAULATPUR BUDGET TRACKER — ANDROID STUDIO PROJECT

Is folder mein Android app ka source project hai. Is environment mein Android SDK/Gradle installed nahi tha, isliye ready-made APK compile nahi ki gayi. APK banane ke liye:

1. Computer par Android Studio install karein.
2. Android Studio > Open par click karke is ZIP ko extract karne ke baad 'GSSS_Daulatpur_Android_Project' folder select karein.
3. Gradle sync complete hone dein. Agar SDK 35 missing ho, SDK Manager se Android SDK Platform 35 install karein.
4. Build > Build Bundle(s) / APK(s) > Build APK(s) chunein.
5. APK aam taur par app/build/outputs/apk/debug/app-debug.apk mein milegi.
6. APK ko apne Android phone mein bhejein, file kholkar install karein. Phone par zarurat pade to Settings mein us file manager/browser ke liye 'Install unknown apps' allow karein.

DATA PRIVACY:
- App mein koi internet permission nahi hai.
- Kharch ke records isi phone ke app WebView storage mein save hote hain.
- App uninstall ya app data clear karne par records mit sakte hain. Regular CSV backup rakhein.
